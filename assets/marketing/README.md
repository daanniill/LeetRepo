# LeetRepo marketing kit

## Campaign idea

**Solve it. Keep it.**

LeetRepo turns the short-lived reward of an Accepted submission into a durable asset: a GitHub archive, a documented solution, and a study-ready history.

## Core messaging

- **One-line pitch:** LeetRepo commits accepted LeetCode solutions to GitHub and turns them into an interview-ready study library.
- **Short pitch:** Every Accepted solution lands in GitHub with a clean README, study metadata, and a record of how you got there.
- **Primary CTA:** Turn Accepted into progress.
- **Supporting CTA:** Build your solve history.

### Feature pillars

1. **Capture automatically** — Push manually or sync when LeetCode accepts a fresh submission.
2. **Organize by default** — Keep one folder per problem, language-specific solution files, and generated READMEs.
3. **Review what matters** — Revisit interview overviews, attempt history, pattern gaps, and spaced-repetition cues.
4. **Own the archive** — Solutions are committed to the GitHub repository the user chooses.

## Ready-to-use copy

### Chrome Web Store short description

Commit accepted LeetCode solutions to GitHub with clean READMEs, attempt history, and study-ready review cues.

### Launch post

Accepted should be the start of your solve history, not the end of it. LeetRepo commits fresh LeetCode solutions to your GitHub repository, documents the approach, and keeps the patterns and attempts ready for interview review.

### Social captions

- Solve it. Keep it. LeetRepo turns every Accepted submission into a clean GitHub commit and a study-ready solution.
- Your LeetCode history already has the raw material for an interview study system. LeetRepo organizes it automatically.
- Accepted → GitHub → review. One workflow, no copy-paste ritual.

## Visual system

- **Primary teal:** `#2f8f8a`
- **Warm ivory:** `#edeee4`
- **Deep ink:** `#211c18`
- **Moss:** `#4e5a37`
- **Apricot accent:** `#e08a4e`
- **Headline style:** rounded, friendly, direct
- **Image motif:** one continuous branch path turning a solve into an archive and review loop

Avoid generic blue SaaS gradients, competitive/gamified language, claims of full automation without the Accepted-submit condition, and claims that user data is stored remotely by LeetRepo.

## Generated artwork prompt

Built-in image generation was used for `source/workflow-hero-art.png` with this production prompt:

> Create a premium editorial 3D illustration of a single accepted coding solution transforming into a neatly organized Git repository and lightweight study system. Use a continuous branch-like path, rounded tactile cards, a contribution-grid motif, deep warm charcoal, teal, warm ivory, muted moss, and restrained apricot. Keep the cluster on the right with negative space on the left. No readable text, brand names, people, hands, screenshots, or logos.
