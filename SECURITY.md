# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in this repository's Security tab. Do not disclose a vulnerability, token, private repository name, solution code, or account data in a public issue.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Reports should receive an initial acknowledgement within seven days. A fix timeline depends on severity and whether GitHub, Chrome, LeetCode, or an AI provider must also act.

## Supported version

Only the latest extension release receives security fixes. Users should keep extension updates enabled, scope tokens narrowly, and rotate any credential that may have been exposed.
